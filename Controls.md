## Everywhere

| Buttons | Does |
|---|---|
| SELECT + Up / Down | Brightness |
| SELECT + Left / Right | Blue light |
| VOL+ / VOL- | Volume |
| VOL+ and VOL- together | Mute |
| Hold POWER | Power menu |

## At power-on

Any button skips the opening: the terminal fades out at once and the shelf comes in. The press
that skips it does nothing else, so A inserts no cart. Once the shelf shows through, a press ends
the opening and does what it does on the shelf. POWER and the lid end it at once. Brightness,
blue light and volume work through it.

## On the shelf

The bar along the bottom says what SELECT and START do.

| Buttons | Does |
|---|---|
| Left / Right | Move along the shelf |
| Up / Down | Jump to the next letter |
| L1 / R1 | Switch between GBA, Game Boy and Game Boy Color |
| Tap A | Insert the cart and resume its last save state |
| Hold A | Insert the cart and start the game fresh |
| X | Open the cart and choose its core (GBA only) |
| START | [[Settings]], including the [[Theme|Shelf Background]] and [[Wi-Fi, SSH and SFTP|Networking]] |
| Tap SELECT | CONTROLS: what every button does, on the shelf and in a game. B or SELECT closes it |

## In a game

| Buttons | Does |
|---|---|
| Hold MENU | Save a state, eject the cart, back to the shelf |
| Double tap MENU | Save state switcher |
| SELECT + MENU | Link screen, see [[Link Play]] |
| SELECT + R1 | Save a state |
| SELECT + L1 | Load the most recent save state |
| SELECT + Y | Colour correction on or off |
| Hold L2 | Rewind |
| Hold R2 | Fast-forward. Double tap R2 to lock it on, again to unlock |
| Hold X / Y | Turbo A / turbo B |
| L1 / R1 | Stretch to fill the screen / original size (Game Boy and Game Boy Color) |

## In Settings and the other menus

The bar along the bottom says B RETURN and A CONFIRM. Keys a screen adds are shown in the middle
of it.

| Buttons | Does |
|---|---|
| Up / Down | Move between rows |
| Left / Right | Change the lit row, on a row that shows ◀ ▶ |
| A | Confirm: open the screen of a row that ends in ›, join the network under the cursor, set the clock |
| B | Back one screen |
| START | In Settings, back to the shelf. On Labels, fetch labels |
| Y | On Network, forget the saved network under the cursor. On Labels, sign out |

## In the save state switcher

| Buttons | Does |
|---|---|
| Left / Right | Flick through the states |
| A | Load the one on screen |
| B | Back to the game |

## On the on-screen keyboard

| Buttons | Does |
|---|---|
| D-pad | Move between keys |
| A | Type the key, or press Shift, #+=, Space, Delete or Done |
| B | Delete the last character. On an empty field, go back |
| X | Shift: capitals, and back |
| Y | Space |
| L1 / R1 | Symbols, and back |
| START | Done |
| MENU | Go back |

## The lid

Closing the lid saves a state and turns the screen off; opening it carries on. Left shut for
three minutes, omega-zero powers off and resumes from that state on the next boot.
